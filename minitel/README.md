# 3615 Home Assistant

Allumer et éteindre les lumières de Home Assistant depuis un Minitel branché sur sa ligne téléphonique.

L'app fait tourner Asterisk, avec un softmodem V.23, et un petit serveur Vidéotex. Côté matériel, il faut un adaptateur téléphonique SIP (j'utilise un Cisco SPA112) et un câble entre la prise T du Minitel et le RJ11 de l'adaptateur.

Le panneau Minitel de la barre latérale permet de tester sans Minitel : il appelle Asterisk comme le ferait l'adaptateur.

Installation et réglages : onglet Documentation.
